Runtime Architecture

Five agents, one shared state

Every ticket flows through a deterministic safety gate first, then classification and routing, then grounded resolution via a knowledge graph, and finally an escalation judge. Compute scales with difficulty — easy tickets resolve in milliseconds, hard ones climb a ladder.

01 · SAFETY

Intake Gate

Regex scan for high-stakes tickets (breach, etc.) → escalate to SOC, bypass the LLM. Sub-5ms.

02 · CLASSIFY

VGAC

Vocabulary-guided SVM + deterministic scorer over a two-layer term vocabulary.

03 · ROUTE

Edge Resolver

Confidence gate → if unsure, a scorer/kNN/SVM agreement ladder, then an LLM tiebreak.

04 · RESOLVE

Graph RAG

Symptom → root cause → vetted resolution traversal. Quality-gated; escalates if no clean fix.

05 · JUDGE

Escalation

Auto-resolve only when confident and consistent; otherwise escalate with full context.

Deliberately lexical (TF-IDF + knowledge graph, no embeddings) for interpretability and zero infrastructure. Semantic vector-DB layer (BGE-M3 + Qdrant) is a documented production seam.
