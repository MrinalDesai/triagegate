A LangGraph that takes different paths depending on what it finds
Six agents over a shared state. They run a battery of data-quality tests; if a problem trips, the graph routes through the full retrain path; if the data is healthy, it takes the conditional edge straight to the judge and changes nothing. Pick the data the agents see, then run it.

Isolated by design — reads data read-only, writes only to improvement/out/, never touches the production model or live router. The conditional edge after plan is a real LangGraph branch: with problems it retrains and, only if it validates better, writes svm_candidate.pkl; with healthy data the baseline is already at ceiling, so it skips straight to the judge and leaves the model unchanged.
